What a skill looks like?

EXTRACTED SKILL

nbr-burn-severity-and-regrowth-change-analysis

Released SkillBank ↗
WHEN TO USE

Use when a user requests a visual analysis of burn severity and vegetation recovery changes over time using normalized burn ratio (NBR) index differences, requiring classification of low, moderate, severe burn, unburned, and enhanced regrowth areas.

PLAN
  1. Call GetAreaBoundary with the specified geographic region to define the study area and generate a geopackage file that serves as the shared workspace.
  2. Call AddIndexLayer with NBR and the first date to compute and store the baseline NBR raster layer.
  3. Call AddIndexLayer a second time with a different month to compute the later NBR raster layer.
  4. Call ComputeIndexChange with the two distinct NBR layers to classify burn severity and regrowth patterns.
  5. … Call ShowIndexLayer, then terminate only after the preview and base layers are successfully generated.
GROUNDED OBSERVATION ROUTING
  • Use the gpkg output from GetAreaBoundary to provide the gpkg argument for both AddIndexLayer calls.
  • Use the gpkg output from GetAreaBoundary to provide the gpkg argument for ComputeIndexChange and ShowIndexLayer.
  • Use the layer_name outputs from AddIndexLayer to provide layer1_name and layer2_name for ComputeIndexChange.
  • Use the diff_layer_name output from ComputeIndexChange to provide the layer_name argument for ShowIndexLayer.
  • … Use the text output from ShowIndexLayer as evidence for the ans argument of Terminate.
TOOL LIST
  • GetAreaBoundaryarea, buffer_m
  • AddIndexLayergpkg, index_type, layer_name, year, month
  • ComputeIndexChangegpkg, index_type, layer1_name, layer2_name, diff_layer_name
  • ShowIndexLayergpkg, index_type, layer_name
  • Terminateans
01 Framework

Teach agents to act
on Earth—once and again.

Geospatial tasks often require long, brittle chains of tool use. SkillEarth preserves what works in those trajectories as modular, retrievable skills that can improve future executions.

01

Skill Extraction

Extract controllable, reusable skills from the components of demonstrated tool trajectories.

→
02

Skill Evolution

Use dual-judge feedback and a GOR graph for grounded, fine-grained skill refinement.

→
03

Skill Decision

Decide whether each evolved skill should be added, merged into the bank, or discarded.
